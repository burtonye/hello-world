## Fruit Box Game - 2 Player Edition

A fun, interactive 2-player game where players take turns drawing boxes around apples that sum to exactly 10!

### How to Play

1. Open `fruit-box-game.html` in your web browser
2. Players take turns selecting apples by clicking and dragging to create a rectangular selection
3. The sum of all apples in your box must equal exactly 10
4. Successfully complete a box to score 1 point
5. First player to reach 10 points wins!

### Features

- Beautiful gradient UI with smooth animations
- Real-time turn indicator
- Score tracking for both players
- Visual feedback for valid/invalid selections
- Responsive design
- Easy to play - just click and drag!

Have fun playing!
